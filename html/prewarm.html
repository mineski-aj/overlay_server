Overlay prewarm

Downloads videos and photos into this browser's cache before the show, so scenes start instantly. Leave this page open until every bar is green.

The cache belongs to the browser that opens this page. For OBS, add this page as a browser source in the same OBS that runs the overlays. Files you change on the server are re-downloaded automatically next time you run it. Add ?auto=1 to start immediately, and &sets=draft-heroes,photos to pick sets.
